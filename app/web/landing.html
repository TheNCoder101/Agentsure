How it works

One call between your agent and the consequences.

Before your agent commits a high-stakes output — a filing, a diagnosis summary, a client email with numbers in it — it calls the gate with the output and the source documents it should be grounded in.

01

Decompose & check

The output is split into atomic factual claims. Every claim is checked against your evidence: semantic entailment, number mismatches, fabricated-citation patterns.

02

Escalate only what's flagged

On standard and strict rigor, only flagged claims go to the LLM judge — never the ones that already passed. Depth where it matters, cost control everywhere else.

03

Verdict + signed receipt

You get supported, unsupported or partially_supported, per-claim evidence, and an HMAC-signed receipt. Anyone can re-verify it at POST /receipt/verify — tamper with one field and it fails.

# Verify an output against evidence — one request curl -s https://api.agentsure.dev/verify \ -H "X-API-Key: vg-••••••••••••" -H "Content-Type: application/json" \ -d '{ "output": "Q3 revenue rose 12% to $4.1M.", "source_documents": [{"id": "10q-2026", "text": "…revenue increased 12% to $4.1M…"}], "rigor_level": "standard" }' # → { "verdict": "supported", "confidence": 0.97, "receipt": { "signature": "…" } }
